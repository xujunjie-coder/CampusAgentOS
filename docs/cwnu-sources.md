# 西华师范大学信源配置说明

## 官网关键词搜索（2026-11-24 接入）

运行 `python tools/add_cwnu_source.py`，即可在“信源管理”新增或启用“西华师范大学官网”。
随后在“采集管理 → 网页采集”选择该信源并输入关键词。

- 主页：[西华师范大学](https://www.cwnu.edu.cn/)。采集调用官网搜索页面使用的公开结构化接口，使用游客权限，不保存个人 Cookie。
- 支持每页 10 条的关键词搜索，应用第一页映射官网第 0 页；无需大模型解析搜索页面。
- 清除关键词高亮 HTML，保留标题、摘要、原始发布日期及官网/校内部门原文链接，接入现有去重入库和后续深度采集流程。
- 本机已实测“奖学金”返回并入库 9 条。官网索引当前该词结果覆盖 2018–2024 年，不能据此认定它已包含最新奖学金政策；引用时须核对年份及适用范围。
- 当前只采集官网搜索索引返回的记录，不会自动全站爬取、导入知识库或开启定时任务。

## 信源列表

### 1. 西华师范大学新闻网

| 字段 | 值 |
|------|-----|
| **name** | 西华师范大学新闻网 |
| **url** | `http://news.cwnu.edu.cn/list.htm` |
| **建议采集频率** | 每日（daily） |
| **enabled** | 是 |

**用途**
西华师范大学官方新闻门户，涵盖学校动态、政策通知、学术活动、科研成果等权威内容。
适合作为校园舆情基线数据来源，也可用于 RAG 知识库建设。

**注意事项**
- 该域名为 HTTP（非 HTTPS），采集时请注意跳转处理。
- 建议仅采集列表页中有更新的条目，避免全量重复抓取。
- 如学校服务器对高频请求有限制，可将采集间隔调整为每日一次（深夜低峰期执行）。

### 4. 百度资讯-西华师大

| 字段 | 值 |
|------|-----|
| **name** | 百度资讯-西华师大 |
| **url** | `https://www.baidu.com/s?ie=utf-8&bsst=1&...&wd={关键字}&pn={分页步长}` |
| **建议采集频率** | 每日（daily） |
| **enabled** | 是 |

**URL 占位符说明**

| 占位符 | 说明 |
|--------|------|
| `{关键字}` | 采集时替换为实际搜索词，如"西华师范大学" |
| `{分页步长pn=0=第一页，pn=10=第二页}` | 百度分页参数，`pn=0` 为第一页，每页 10 条，逐步递增 |

**用途**
通过百度资讯搜索聚合互联网上与西华师范大学相关的新闻、论坛讨论、社交媒体内容，
用于舆情监测、风险预警和口碑分析。

**注意事项**
- 百度搜索结果页有反爬机制，建议控制采集速率（每次间隔 ≥ 3 秒），使用真实 UA 和 Referer。
- 该信源的 `url` 含占位符，采集前需由采集管理模块完成关键字替换。
- 结果为综合聚合数据，准确性参差，需结合其他权威信源交叉验证。
- 百度资讯接口或页面结构可能随时变化，需定期维护选择器。

## 执行说明

```bash
# 在仓库根目录执行（需先激活虚拟环境）
.\\venv\\Scripts\\python.exe tools\\seed_sources_cwnu.py
```

脚本具备**幂等性**：已存在同名信源时自动跳过，不产生重复数据，可安全重复执行。

执行完成后，可在系统后台「**数据采集 → 信源管理**」（`/admin/sources`）中查看和管理这5个信源。

## 字段映射说明

> [!NOTE]
> `sources` 表实际字段为 `id, name, url, headers, description, enabled, created_at`。
> 任务规格中的 `source_type` 和 `update_frequency` 字段**不在当前表结构中**，
> 相关含义通过 `description` 字段文字说明保留，待后续扩展时补列。

| 任务规格字段 | 表字段映射 | 说明 |
|-------------|----------|------|
| `name` | `name` | 信源唯一业务主键 |
| `url_template` | `url` | URL 模板，支持占位符 |
| `headers` | `headers` | JSON 字符串入库 |
| `description` | `description` | 含用途和频率说明 |
| `enabled` | `enabled` | 1=启用，0=禁用 |
| `source_type` | ——（暂无此列） | 通过 description 文字说明 |
| `update_frequency` | ——（暂无此列） | 通过 description 文字说明 |
