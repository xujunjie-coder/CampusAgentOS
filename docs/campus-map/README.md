# 校园三维地图（行署校区 / 华凤校区）

2026-11-24 更新：右侧方向按钮支持平移视图；华凤校区名称按用户截图校正，理科楼 A/B/C 提供独立标注与聚焦区域。原连体轮廓未拆为实测建筑，新增校门仍是路口示意点位。校正保存在 `scripts/huafeng_name_corrections.mjs`，模型重建后自动应用；来源及估算高度提示继续保留。

平台入口 `/campus-map`，侧栏“校园三维地图”进入，须登录。支持顶部一键切换 **行署校区（老区）** 与 **华凤校区（新区，一期 + 二期）**（亦支持通过 `?campus=huafeng` 直达华凤校区）：
- **行署校区**：使用 [SCSWiki 行署校区三维地图](https://scswiki.com/start/xingshu-campus-map) 的学生整理白模和 OpenStreetMap 矢量数据。
- **华凤校区**：基于 OpenStreetMap（`relation/19478636 西华师范大学(华凤校区)`，ODbL 1.0）矢量轮廓与 `EPSG:32648` 局部米坐标，经 [build_huafeng_campus_map.mjs](../../scripts/build_huafeng_campus_map.mjs) 自动生成白模（115 栋建筑轮廓、53 栋已命名、62 栋待核验候选、5 处水体、53+ 块运动场、校内外道路与步行路），所有未命名楼块、重复楼名及出入口均登记在 `app/static/maps/huafeng-campus/buildings-review.json` 与 `landmarks.json` 中待核验。

## 本次实现

- 按楼块面法向区分屋顶和墙面材质，用图例区分道路、步行路、运动场和水体。水面动效沿用原模型水域范围，并遵循系统减少动态效果设置。
- 透视视角可旋转，正交俯视沿模型坐标系北向，比例尺随缩放更新。测距在模型地面选取两点，按局部米坐标计算水平直线距离。比例尺与距离均以模型为基准；步行与通行安排请以现场为准。
- 校门优先标注，俯视时显示避让后的建筑标注。宽屏透视全景也提供图书馆、教学楼、体育馆和行署礼堂等定位参考，近看时突出选中楼块。校门点位为示意，`landmarks.json` 记录了参考像素和仿射配准参数。
- 可用搜索、标注和楼块选择建筑。详情显示模型原点的东向和北向偏移、楼块几何高度及审查提示。候选建筑、名称冲突和未实测信息继续标注待核验。
- Shift 或右键拖动可在透视视角平移，触屏可双指缩放和平移。俯视中直接拖动即可平移。键盘方向键移动视图，加减号缩放，数字 0 恢复当前视角的全校范围。测距时可按回车选取画面中心。

## 证据与模型边界

审查文件按 1–14、15–28、29–42 分组，覆盖所有 42 栋；对应报告位于本目录，机读 JSON 位于 `app/static/maps/xingshu-campus/`。审查未完成腾讯逐栋 3D 图像对照，没有根据估计名称新增所谓真实立面。GLB 内部所有建筑均非实测；内部旧名与 manifest 不一致并不自动证明其中一方正确，因此保留原清单名并提示差异。

原始 manifest 的 WGS84 原点和 UTM EPSG:32648 局部坐标可用于后续配准。不能把局部米坐标直接当经纬度，也不能把 WGS84 数值直接用于要求 GCJ-02 的底图。正式叠加需完成坐标转换、控制点对齐与偏差核验。

真实细化应逐栋补充：能确定建筑身份和拍摄方向的当前照片/全景、轮廓控制点、层数/高度依据、屋顶结构、资料时间和许可。先解决名称身份冲突，再修改体量；新几何需保留证据、版本与包围盒校验，不以外观相似代替位置或身份核验。

若要接入真实卫星底图，可使用地图厂商正式 SDK；是否有该校区的详细三维数据必须实测覆盖，不能将移动端截图视作 Web SDK 的覆盖证明。高德官方示例区分[卫星图层和三维楼块](https://lbs.amap.com/demo/javascript-api-v2/example/layers/buildings)，以及[自定义三维数据](https://developer.amap.com/demo/list/jsapi-v2)。正式接入前需要项目可用的 SDK 凭据、域名配置与适用的数据使用权限。本版没有下载瓦片、提取腾讯模型、解密学校全景配置或接入收费服务。
