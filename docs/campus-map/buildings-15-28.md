# 行署校区第15至28栋建筑核对

核对日期：2026-11-22。范围只含行署校区，不使用华凤校区截图作为建筑位置或形态证据。

本轮未修改GLB或清单，也未制作推测立面。14栋均标记 `is_measured=false`。目前能安全实施的是保留已有几何、添加可关闭的名称标签、对冲突或候选建筑标注“待核验”；不能宣称腾讯地图逐栋复原完成。

## 核对方法与限制

- 几何尺寸直接来自GLB POSITION accessor的min/max，节点未带额外变换。表内顺序为东西向X跨度 × 南北向Z跨度 × 高度Y；这是轴对齐包围盒，不是实测长宽，也不能直接与旋转建筑的面阔/进深比较。
- `confidence`和`modelGrade`是原资源的自报值。本轮不替其重新定义等级，也不把 `verification=named` 当独立证据。
- 模型中的 `pano-NNN` 只是旧资源索引；本轮未验证它们对应的实际全景画面。
- 官方全景入口及它引用的 `tour.xml` 均返回HTTP 200，但配置是 `<encrypted>` 包装。本轮未绕过其加密、未下载全景图像、未移用其纹理；因此只确认入口可达，未完成影像对照。
- 未取得可逐栋定位的腾讯3D实景证据，卫星平面影像也不足以独立确定立面、楼层和屋顶高度。
