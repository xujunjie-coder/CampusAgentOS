# 数据瞭望系统使用手册（后台管理端）

## 一、登录与角色

1. 访问 `/auth/login` 输入账号密码登录；系统同时支持「人脸登录」，需在用户管理中录入人脸后方可使用。
2. 角色分为超级管理员、管理员、普通用户：超级管理员可访问「系统设置」全部能力，普通后台角色访问该页返回 403。
3. 连续登录失败达到阈值（默认 5 次）锁定 10 分钟，策略可在「系统设置 → 安全与会话」调整。

## 二、后台菜单结构

- **首页 / 控制台**：用户数、角色数、最近注册、系统信息概览。
- **数据看板**：数智大屏（`/admin/dashboard`）、统计报表（`/admin/reports`）。
- **数据采集**：信源管理、采集管理、数据仓库（`/admin/warehouse`）、知识仓库（`/admin/knowledge`）。
- **模型服务**：模型引擎（`/admin/models`）。
- **智能体服务**：数字员工（`/admin/employees`）、工具链路（`/admin/tools`）、智能舆情（`/admin/sentiment`）。
- **系统管理**：用户、角色、菜单、系统设置（`/admin/settings`）。
- **系统运维**：定时任务、会话管理、对话管理、工作空间。

## 三、数智大屏操作

1. 大屏由三列组成：左列地图与信源排行，中列趋势与风险，右列热词与预警流。
2. 底部浮动条为「大屏智能问答」，支持文字与语音提问，常用问题：最新数据情况、风险预警情况、信源采集排名、近七天趋势。
3. 右上角「全屏」按钮调用浏览器全屏，用于投屏演示；窗口宽度小于 860 像素时自动改为单列堆叠，趋势面板按设计隐藏，全屏或拉宽后恢复。
4. 大屏数据由 SSE 实时推送，默认 10 秒一次，可在「系统设置」调整推送间隔（5–120 秒）。

## 四、统计报表

1. 页面顶部可切换近 7 / 14 / 30 / 90 日范围，切换后全部图表与 KPI 同步刷新，右上角显示数据生成时间。
2. 每张图表右上角有 PNG 按钮，可单独导出；「导出全部 PNG」会依次导出各图表。
3. 图例可勾选（采集条目、对话消息、模型 Token 右轴），实时推送开关打开后图表按间隔自动刷新。
4. 底部「最新采集」表格展示最近入库条目，点击标题跳转原始信源。

## 五、智能舆情预警台

1. 顶部 KPI 四卡：高风险、关注、常规、待重试，数值来自库内实时聚合。
2. 「分析待处理条目」触发批量研判；分析失败会在顶部显示原因提示，常见原因是模型服务未启动。
3. 风险流支持按等级筛选（全部 / 高风险 / 关注 / 常规 / 待重试），筛选作用于服务端已渲染的全部行。
4. 新高风险到达时按设置播放提示音或发送桌面通知。

## 六、系统设置

1. **系统标识**：系统名称、副标题、Logo、Favicon、大屏水印、刷新间隔，改完即时生效，无需重启。
2. **数据库连接**：默认 SQLite，支持切换 MySQL；切换前会先试连，失败自动回滚，不迁移历史数据。
3. **语音与人脸模型**：语速、自动播报、语音识别开关、人脸引擎与阈值，保存后写入配置。
4. **安全与会话**：会话有效期、登录失败锁定、审计保留天数，保存后写回 `.env` 并热重载。

## 七、常见问题

1. 图表空白：先确认是否有数据（KPI 是否为 0），再检查浏览器是否加载了 ECharts 与图表脚本。
2. 「连接中」长时间不消失：WebSocket 被网络设备拦截，页面会自动重连，必要时点「重新连接」。
3. 分析按钮无效：多为模型服务不可达，看顶部提示，启动模型代理后重试。
4. 保存设置后仍未生效：检查进程配置是否被 `.env` 覆盖，或查看日志中的热重载记录。
