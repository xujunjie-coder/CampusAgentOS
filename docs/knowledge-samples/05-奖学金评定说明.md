# 奖学金评定说明

**关键词**：国家奖学金、国家励志奖学金、校级奖学金、奖学金申请流程、评定标准、评定时间、综合素质测评

---

## 一、概述

西华师范大学奖学金体系分为**国家级**、**省级**和**校级**三个层次，旨在激励学生德智体全面发展、积极进取。奖学金评定每学年进行一次，以上一学年的综合表现为依据。

> 请以西华师范大学官网学生资助管理中心最新发布的通知为准，以下内容为通用参考框架。

---

## 二、国家级奖学金

### 2.1 国家奖学金

**奖励金额**：**8000元/年**

**资助对象**：全日制本科在读学生（二年级及以上）

**评定条件**（须同时满足）：

1. **品德条件**：热爱祖国，遵纪守法，道德品质优良；无任何纪律处分记录；
2. **学业条件**：
   - 上一学年全部课程无不及格科目；
   - 学业成绩**排名位于本专业同年级前5%以内**（各校名额有限，实际排名要求以当年通知为准）；
3. **综合表现**：积极参与社会实践、志愿服务、科技竞赛等，综合素质测评成绩优异；
4. **名额限制**：国家奖学金名额有限，全国高校总量控制，学校分配到各学院，竞争较为激烈。

**申请材料**：
- 个人申请书
- 上一学年成绩单（教务处盖章）
- 荣誉证书复印件（如有）
- 辅导员推荐意见

---

### 2.2 国家励志奖学金

**奖励金额**：**5000元/年**

**资助对象**：全日制本科在读学生（二年级及以上）中，**品学兼优且家庭经济困难**的学生

**评定条件**（须同时满足）：

1. **品德条件**：同国家奖学金；
2. **学业条件**：学业成绩**排名位于本专业同年级前20%以内**；
3. **经济条件**：须持有县级及以上民政部门出具的**家庭经济困难认定材料**，或已在全国学生资助管理信息系统中完成困难认定；
4. **名额限制**：全国总量控制，按省分配，各校名额以当年教育厅文件为准。

**注意事项**：
- 国家励志奖学金与**国家助学金不可同时申请**（两者均面向困难学生，只能择一）；
- 已享受国家奖学金者，不可再申报国家励志奖学金。

---

## 三、省级奖学金

四川省设有**省政府奖学金**，面向品学兼优的全日制本科生，金额及名额以四川省教育厅当年文件为准。评定条件参照国家奖学金，但名额相对国家奖学金略多。

> 请以四川省教育厅及西华师范大学学生资助管理中心当年通知为准。

---

## 四、校级奖学金

### 4.1 校级综合奖学金（一般性奖学金）

西华师范大学设立**校级综合素质奖学金**，依据学生综合素质测评成绩排名，按比例发放：

| 等级 | 比例（参考） | 金额（参考） |
|-----|------------|------------|
| **一等奖学金** | 专业前5% | 2000元/年 |
| **二等奖学金** | 专业前15% | 1500元/年 |
| **三等奖学金** | 专业前25% | 1000元/年 |

> 以上数据为参考框架，**实际金额和比例以学校当年正式文件为准**。

### 4.2 单项奖学金

针对在某一方面表现突出的学生，学校还设有以下单项奖学金：

- **科技创新奖学金**：在国家级、省级学科竞赛中获奖者
- **社会活动奖学金**：在志愿服务、社会实践中表现突出者
- **文体优秀奖学金**：在文艺、体育方面为学校争光者

各单项奖学金评定标准及申报方式以当年学生处通知为准。

## 五、综合素质测评说明

综合素质测评（简称"综测"）是校级奖学金评定的核心依据，通常由以下几个维度构成：

| 测评维度 | 权重（参考） | 主要内容 |
|---------|-----------|---------|
| **学业成绩** | 60%–70% | 各科目成绩加权平均 |
| **思想品德** | 10%–15% | 政治表现、遵纪守法情况 |
| **社会实践** | 10%–15% | 志愿服务、社团活动、实习实践 |
| **文体活动** | 5%–10% | 体育达标、文艺参与 |

> 具体测评方案以学校学生处发布的《综合素质测评办法》为准。

## 六、申请流程

```
个人申请 → 班级民主评议 → 辅导员审核 → 学院初评公示 → 教务处/学生处复核 → 学校评审委员会终审 → 结果公示 → 发放奖学金
```

### 详细步骤说明

1. **个人自荐**：符合条件的学生在规定时间内填写申请表，准备材料。
2. **班级评议**：由班委或全体同学对候选人进行民主评议，确保公平公正。
3. **学院初审**：各学院奖学金评定委员会对材料进行核实，确定推荐名单并**在学院内公示不少于3个工作日**。
4. **学校终审**：教务处、学生处、学生资助管理中心对学院推荐名单进行复核，最终由学校评审委员会确定获奖名单。
5. **结果公示**：最终名单在校园网上**公示5个工作日**，无异议后正式发文并发放奖学金。
6. **异议处理**：公示期内如有异议，可向学生资助管理中心书面反映，学校将在规定时间内给予答复。

## 七、评定时间节点

| 时间节点 | 事项 |
|---------|-----|
| 每年**9月初** | 学校发布当年奖学金评定通知 |
| **9月中旬** | 学生提交申请材料截止 |
| **9月下旬** | 学院完成初评、公示 |
| **10月初** | 学校完成终审 |
| **10月中旬** | 结果公示及异议受理 |
| **10月底至11月** | 奖学金发放至学生银行卡 |

> 以上时间节点为往年参考，**具体时间以当年学校官网通知为准**。

## 八、常见问题 FAQ

**Q1：大一新生可以申请奖学金吗？**
A：国家奖学金和国家励志奖学金面向二年级及以上学生；部分校级奖学金可能对大一新生有特殊安排，请关注当年通知。

**Q2：有挂科记录能否申请奖学金？**
A：国家级奖学金要求上一学年所有课程无不及格，有挂科记录通常不符合申请条件。校级奖学金的要求请以当年文件为准。

**Q3：休学期间能否参与奖学金评定？**
A：休学期间通常不参与奖学金评定，复学后可正常参与。

**Q4：奖学金需要缴税吗？**
A：依据现行税法，奖学金收入一般免征个人所得税，但具体以国家税务规定为准。
