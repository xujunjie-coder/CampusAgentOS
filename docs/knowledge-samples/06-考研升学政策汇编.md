## 一、概述

升学是西华师范大学学生实现个人发展的重要路径之一。本文汇编了**推荐免试攻读研究生（推免）**和**全国硕士研究生招生统一考试（统考）**两大主要升学方式的政策信息，供在校生参考规划。

## 二、推荐免试攻读研究生（推免）

### 2.1 政策背景

推免制度是教育部授权部分高校向优秀应届本科毕业生提供免初试直接攻读研究生资格的制度。**西华师范大学具有推免生资格**，可向外推送推免生至全国各研究生培养单位。

### 2.2 推免资格条件

申请推免资格须同时满足以下条件：

1. **学籍条件**：全日制应届本科生，就读于具有推免资格的专业；
2. **学业成绩**：
   - 前三学年（大一至大三）各学期的**加权平均成绩**（GPA）排名位于本专业前列；
   - 通常要求**无不及格科目记录**，部分专业要求无重修科目；
3. **综合素质**：综合素质测评成绩优秀，参与科研、竞赛、社会实践等加分项；
4. **品德条件**：政治素质过硬，无违纪处分记录；
5. **外语要求**：部分目标招生单位会要求英语四六级成绩或其他语言证明，建议尽早准备。

### 2.3 西华师范大学各学院推免比例说明

> **重要说明**：推免名额由教育部每年根据高校整体办学质量下达，各学院推免比例以学校研究生院当年公布的文件为准。

以下为通用框架说明：

- 推免名额通常不超过该专业应届本科毕业生总数的**15%**（教育部上限规定），实际比例因学校、专业而异；
- **重点学科、特色专业**（如西华师大的教师教育、生态学等）可能获得相对较多名额；
- 推免生须参加各招生单位的**夏令营或推免生考核**，通过方可获得录取资格；
- 建议学业成绩排名位于**专业前10%**的学生积极关注推免政策。

### 2.4 推免工作时间安排

| 时间节点 | 事项 |
|---------|-----|
| **大三下学期（3–5月）** | 关注各目标院校夏令营招募信息 |
| **5–8月** | 参加各院校举办的**优秀大学生夏令营** |
| **9月初** | 教育部统一开放推免系统（"推免服务系统"） |
| **9月中旬** | 学校完成推免资格认定，公示推免候选名单 |
| **9月下旬** | 推免生在系统中填报志愿，接受招生单位考核 |
| **9月底前** | 推免生确定录取单位，签订接收函 |

## 三、全国硕士研究生招生统一考试（统考/考研）

### 3.1 考试时间安排

全国硕士研究生招生统一考试（统称"考研"）**每年12月举行**，具体时间由教育部公布：

- **考试时间**：通常为**每年12月下旬的周六、周日**（约12月23–24日前后，以教育部当年公告为准）
- **报名时间**：
  - **预报名**：每年**8月下旬至9月初**（约8月底，仅面向应届本科生）
  - **正式报名**：每年**10月下旬至11月初**（约10月25日–11月5日，以当年公告为准）
- **现场确认（网上确认）**：通常于**11月**进行，须上传照片、确认报名信息
- **成绩查询**：次年**2月下旬**（以当年安排为准）
- **国家线公布**：次年**3月**
- **复试时间**：次年**3–4月**

### 3.2 初试科目说明

| 类别 | 科目 |
|-----|-----|
| 思想政治理论 | 满分100分，全国统考 |
| 外国语（英语一/英语二/日语等） | 满分100分，全国统考 |
| 业务课一（数学或专业基础课） | 满分150分，统考或自命题 |
| 业务课二（专业课） | 满分150分，各招生单位自命题为主 |

### 3.3 备考建议时间规划

```
大一～大二：打好基础，重视英语四六级，多参与科研活动
大三上：确定升学意向，了解目标院校往年分数线
大三下：开始系统备考，参加夏令营（若有推免意向）
大四上（9–12月）：全力冲刺，12月参加统考
大四下（1–4月）：等待成绩、参加复试调剂
```

## 五、考研常见问题 FAQ

**Q1：西华师大的推免生可以报考哪些学校？**
A：推免生可在教育部推免服务系统中填报全国任意具有招生资格的研究生培养单位，不受地域限制。

**Q2：考研报名时学历认证怎么做？**
A：在学学生使用**学信网**进行学籍认证；应届毕业生报名时使用应届本科生身份，参加复试前须完成学历学籍核验。

**Q3：跨专业考研有哪些注意事项？**
A：跨专业考研须重点关注目标专业的业务课考试范围，建议尽早联系目标院校研招办获取参考书目和考试大纲。

**Q4：考研成绩不理想，可以调剂吗？**
A：可以。初试成绩达到国家线且未被第一志愿录取的考生，可在教育部调剂系统中填报调剂志愿，时间通常在次年3–4月。
