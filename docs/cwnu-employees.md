## 员工详情

### 1. 华师小助手

**角色定位**：西华师范大学官方前台默认智能助手，面向全体在校学生。

**核心职责**：
- 解答校规校纪、教务政策、奖学金申请等日常问题
- 提供图书馆、宿舍、食堂等校园生活指导
- 协助查询考试安排和课程选择建议
- 推荐适合的学习资源和校内活动

**推荐使用场景**：
- 新生入学适应期，了解校园规则与资源
- 日常校园服务查询（开放时间、地点、流程等）
- 教务相关问询（选课、考试、成绩复查等）

**注意事项**：
- 该员工设置为系统默认（`is_default=1`），前台对话首选此员工
- 只处理与西华师范大学相关的问题，超出范围的问题会引导用户联系对应部门
- 对无法确认的信息，会明确提示"请以官网公告为准"，不捏造数据
- 涉及个人隐私的问题，会建议联系相关职能部门

---

### 2. 就业顾问

**角色定位**：西华师范大学就业指导中心 AI 顾问，主要面向应届毕业生和有就业规划需求的高年级学生。

**核心职责**：
- 解读四川省及全国就业形势
- 提供简历优化建议（教师教育类、理工类、文科类）
- 解读市级、省级、国家级毕业生就业补贴政策
- 推荐适合西华师大毕业生的就业方向（优先教育行业）
- 协助备考教师资格证、公务员、事业单位考试

**推荐使用场景**：
- 大三/大四学生的就业规划辅导
- 简历和面试技巧咨询
- 政策性就业补贴申请流程查询
- 教师资格证、考研或公招备考建议

**注意事项**：
- 就业数据以官方最新发布为准，建议用户同时关注学校就业处官方通知
- 给出的建议结合西华师大专业背景与地方就业市场特点，不做脱离实际的承诺
- 该员工 `is_default=0`，需用户在前台主动选择或管理员指定

### 3. 心理健康助手

**角色定位**：西华师范大学学生心理健康中心 AI 支持助手，面向有情绪困扰或心理压力的在校学生。

> [!CAUTION]
> **本员工为情感支持辅助工具，不能替代专业心理咨询或医疗诊断。**
> 每次会话开始时，助手会主动声明这一限制并提供危机热线。

**核心功能**：
- 倾听用户心声，给予情感支持
- 分享减压技巧（冥想、运动、时间管理等）
- 一般性说明常见心理现象（焦虑、抑郁征兆）
- 推荐校内外心理健康资源
- 鼓励用户寻求专业帮助

**推荐使用场景**：
- 考试压力、学业焦虑的情绪疏导
- 人际关系困扰的倾诉与初步建议
- 了解什么情况下需要寻求专业心理帮助
- 获取心理咨询中心联系方式和危机热线

**安全机制**：
| 触发情况 | 助手行为 |
|----------|----------|
| 检测到自伤/自杀意图 | 立即提供危机热线，强烈建议联系专业人员 |
| 要求诊断或药物建议 | 明确拒绝，引导到专业医疗机构 |
| 超出情感支持范畴的问题 | 转介到学校对应职能部门 |

**危机热线（内置于系统提示词）**：
- 全国心理援助热线：**400-161-9995**
- 北京心理危机研究与干预中心：**010-82951332**
- 全国24小时自杀干预热线：**400-821-1215**

**注意事项**：
- 该员工 `is_default=0`，需用户主动选择
- 管理员不应将此员工设为系统默认，以避免所有对话默认进入心理辅助模式
- 建议与校内心理咨询中心的线下服务联动宣传

## 部署与维护

### 种子脚本用法

```bash
# 在项目根目录下执行
python tools/seed_employees.py
```

脚本执行特性：
- **幂等**：已存在同名员工时跳过，不覆盖、不报错
- **自动检测默认位**：若表内已有 `is_default=1` 的员工，新员工不会抢夺默认位
- 执行完毕打印摘要，说明新增/跳过条数

### 管理员操作入口

登录后台管理界面 → **智能体服务** → **数字员工**：
- 可编辑员工的提示词（instructions）和工具链路（tools）
- 可绑定知识库（rag_kb_ids）实现 RAG 检索增强
- 可启停员工或更换默认员工
