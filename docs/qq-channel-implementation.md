# QQ 频道快速检索实施记录

## 当前流程

1. 本机管理员在 `/collect` 点击“连接腾讯频道”，在腾讯窗口自行扫码登录并确认频道权限。专用浏览器资料保存在 `database/qq-channel-browser/`，已排除版本控制，不读取日常浏览器或 QQ 密码。
2. 输入频道号和关键词，通过腾讯实际频道内搜索入口 `/g/search?guildNum=...&keyword=...` 查询，选择“帖子”分类，校验范围为本频道。权限或加载失败时明确报错，不退回全站或扫描动态。
3. 合并关键词结果，按帖子 ID 去重。初次只保存搜索卡片摘要和公开互动数，不打开帖子详情、不读取评论。
4. 按赞＋评＋转降序，同热度按显示时间从新到旧排序。月日和相对时间需推算作为日期筛选和排序键，页面保留腾讯原始时间。排序仅覆盖已取得的结果。
5. 点击“人工审核 · 加载本帖评论”，才读取该帖完整正文、评论和回复，保留上下文。已完成结果复用，失败可重试；其他帖子不会展开。
6. 人工可保存“待审核 / 普通反馈 / 需要核实”，需要核实须填写依据。AI 初筛需先取得全文，证据必须来自当前原文，不覆盖人工结论。关键词相关性和负面情绪不等于违规，不自动举报、处罚或发帖。

## 任务与限制

- 后台任务、结果、审核和按帖评论任务持久化，支持进度、停止、历史、分页及重启中断恢复。
- 单进程同时执行一个连接、检索或评论任务；多进程需共享队列和锁。
- 数量、翻页、评论条数/滚动和运行时间均有上限。默认最多 20 帖、搜索翻页 10 次、当前帖评论 80 条。
- 腾讯切换到“帖子”会发起第二次请求，必须等待完成；加载骨架不能当成零结果。结果不代表全部历史。
- 只读取有权访问的网页，不覆盖聊天子频道、图片 OCR、音视频转写。遇验证或权限限制停止。正在等待的页面请求可能需约 30 秒返回。
- 接口沿用后台登录、菜单权限和 XSRF；连接入口额外限制本机管理员。新任务独立保存快照，不自动套用旧审核结论。

- 采集真正的腾讯频道“热门”页。等待客户端初始化及热门页请求完成后，只累计卡片文字与公开互动数，最多候选 50 篇、翻页 15 次，从取得的样本选前 20 篇，热度相同优先显示时间较近的帖子。不加载评论、不读取成员列表或作者资料，不声称覆盖过去24小时全部内容。
